# 🤖Архитектура автокодировщика

## 📌 Содержание проекта

Проект разбит на три ключевых этапа (ноутбука):
1. **`l9z1.ipynb` — Базовый свёрточный автокодировщик с 2D Bottleneck** Фокусируется на жестком сжатии изображений рукописных цифр (классы 0, 1, 3) в двумерное пространство для оценки разделимости латентных представлений в реальном времени.
2. **`l9z2.ipynb` — Оптимизированный автокодировщик со снижением ошибки** Модификация архитектуры для повышения качества реконструкции (MSE < 0.009) по всему спектру классов датасета MNIST.
3. **`l9z3.ipynb` — Шумоподавляющий автокодировщик (Denoising Autoencoder)** Реализация сквозной модели удаления искусственного гауссова шума из зашумленных входных данных с последующим восстановлением четких контуров.

---


## 📐 Архитектуры моделей и задачи

### 1. l9z1: Сжатие в 2D-пространство и кастомные Callbacks
* **Задача:** Отфильтровать датасет MNIST, оставив только цифры `[0, 1, 3]`. Сжать их представление до вектора из 2 элементов (линейная активация), обучить модель за 10 эпох и добиться финальной ошибки $MSE < 0.034$.
* **Особенность:** Написание пользовательского коллбэка `LambdaCallback(on_epoch_end=...)`, который в конце каждой эпохи выполняет предсказание энкодера на обучающей выборке и визуализирует (с сохранением в `.jpg`), как классы обособляются друг от друга в двумерном пространстве.
* **Структура модели:**
  * **Encoder:** Вход (28x28x1) → Conv2D(32) + BatchNorm + MaxPool → Conv2D(64) + BatchNorm + MaxPool → Flatten → Dense(64) → Bottleneck (Dense(2, activation='linear')).
  * **Decoder:** Вход (2) → Dense(7x7x64) → Reshape → Conv2DTranspose(64, strides=2) + BatchNorm → Conv2DTranspose(32, strides=2) + BatchNorm → Conv2D(1, activation='sigmoid').

### 2. l9z2: Оптимизированный Автокодировщик
* **Задача:** Достижение высокого качества реконструкции на всех 10 классах MNIST с жестким критерием финальной ошибки $MSE < 0.009$.
* **Особенность:** Подбор параметров регуляризации слоев (Batch Normalization), увеличение емкости скрытых слоев и оптимизация шага обучения в `Adam(learning_rate=0.001)`.

### 3. l9z3: Модель шумоподавления (Denoising)
* **Задача:** Обучение сети отображать зашумленные матрицы признаков в исходные чистые изображения.
* **Математика шума:** К оригинальным тензорам $X$ добавляется нормальное распределение:
  $$X_{noisy} = X + \text{noise\_factor} \times \mathcal{N}(0, 1)$$
  После чего значения принудительно клипируются в диапазон $[0.0, 1.0]$.
